## Guía de esta copia

### Estructura
[src](./src) contiene la interfaz y [e2e](./e2e) las pruebas de navegación. [angular.json](./angular.json) define el workspace. [INSTALAR.txt](./INSTALAR.txt) conserva los pasos históricos de instalación.
### Desarrollo local
Revisa [package.json](./package.json) y [package-lock.json](./package-lock.json) para acordar la versión de Node y las dependencias. Configura el backend del ambiente de desarrollo y usa `npm run start`. Valida cambios con `npm run build`, `npm run test` y, cuando corresponda, `npm run e2e`.
### Integraciones y entornos
Confirma con el backend de prueba los cambios de rutas y contratos. Los scripts de despliegue del manifiesto se usan con un destino autorizado.
